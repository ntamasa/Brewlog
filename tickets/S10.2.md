**Goal:** Add the search text to the journal store and the URL, debounced by 250 ms.

**Read first:**
- Story → Frontend, Acceptance criteria (R5), Business rules (B3, B17, B20)

## Files that change
- modify `frontend/src/app/journal/journal.store.ts` (+ spec): `setSearch`, `isFiltered`.
- modify `frontend/src/app/journal/journal-query.ts` (+ spec): `q`.
- modify `frontend/src/app/journal/journal-page/journal-page.ts` (+ spec): URL writing in one place.

## Names and signatures
- `JournalStore.setSearch`: `rxMethod<string>` with `debounceTime(250)`, `distinctUntilChanged()`, then `setQuery({ ...query(), q: text, page: 1 })`.
- `JournalStore.isFiltered`: computed, true when `query().q.trim() !== ''` (later stories add the filters).
- `queryFromParams` / `queryToParams`: add `q` (omitted when blank after trim; written trimmed).
- `JournalPage`: replace the URL writing of the pagination handler with one `effect` that calls `router.navigate([], { queryParams: queryToParams(store.query()) })` whenever `store.query()` changes.

## Tests that prove it
**Seam:** unit (`JournalStore`) · **Setup:** TestBed, fake `BrewApi`, `vi.useFakeTimers()` · **Mocked:** API

**Happy path**
1. Given page 3, when `setSearch('  kenya ')` and 250 ms pass, then the fake API is called once with `q: '  kenya '` and `page: 1` (the API client trims) (R5).
2. When `setSearch('k')`, `setSearch('ke')`, `setSearch('kenya')` within 100 ms each, then after 250 ms there is exactly one call, with `q: 'kenya'` (R5).

**Negative**
3. When `setSearch('kenya')` and only 249 ms pass, then no call is made (R5).
4. `isFiltered` is false for `q: '   '` and true for `q: 'kenya'` (R5).

**Seam:** unit (`journal-query`) · **Setup:** Vitest · **Mocked:** nothing
5. `queryToParams({...DEFAULT_QUERY, q: '  kenya '})` → `{ q: 'kenya' }`; `queryFromParams(?q=kenya)` → `q: 'kenya'` (R5).
6. `queryToParams({...DEFAULT_QUERY, q: '   '})` → `{}` (R5).

**Seam:** integration (`JournalPage`) · **Setup:** TestBed, real store and API, `vi.useFakeTimers()` · **Mocked:** HTTP
7. Given `/journal`, when the store's search is set to "  kenya " and 250 ms pass, then GET `/api/brews?q=kenya&sort=NEWEST&page=1` is sent and the URL contains `q=kenya` (R5).
