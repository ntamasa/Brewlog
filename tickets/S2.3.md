**Goal:** Build the brew card and the two shared pieces it uses: the method icon and the bean rating (display).

**Read first:**
- Story → Frontend, Acceptance criteria (R2), Business rules (B22)
- `design/DESIGN.md` (components `brew-card`, `bean-rating`, `roast-tag`, `method-icon`), `design/screens/brews.md` (Layout 5), `design/prototype/screens/brews.html`, `design/prototype/components.css`, `design/screenshots/brews.default.desktop.png`

## Files that change
- create `frontend/src/app/shared/method-icon/method-icon.ts` (+ `.scss`, `.spec.ts`)
- create `frontend/src/app/shared/bean-rating/bean-rating.ts` (+ `.html`, `.scss`, `.spec.ts`): display mode only; the input mode comes in the "Log a brew" story.
- create `frontend/src/app/journal/brew-card/brew-card.ts` (+ `.html`, `.scss`, `.spec.ts`): `mat-card` with the markup and styles of the prototype card.

## Names and signatures
- `MethodIcon`: `iconKey = input.required<string>()`; renders `<mat-icon [svgIcon]="iconKey()" aria-hidden="true">`.
- `BeanRating`: `value = input<number | null>(null)`; display: 5 beans (`bean-fill` up to `value`, `bean` after), wrapper `role="img"` with `aria-label` "n of 5 beans".
- `BrewCard`: `brew = input.required<Brew>()`, `highlighted = input(false)` (adds the class `brew-card-highlight`). Shows: `MethodIcon` + method name, name, "Bean · Origin", `BeanRating`, roast tag (swatch + `LIGHT`/`MEDIUM`/`DARK`), notes clamped to 3 lines (CSS `-webkit-line-clamp: 3`) or muted italic "No tasting notes", `formatDate(brewDate)`.

## Tests that prove it
**Seam:** component · **Setup:** TestBed, `provideHttpClient()` + `provideHttpClientTesting()` for the sprite · **Mocked:** HTTP

**Happy path**
1. Given brew Kenyan Morning (AA Kiambu, Kenya, Pour Over/`pour-over`, `LIGHT`, 5, 2026-10-28, notes "Bright and juicy"), then the card shows "Pour Over", "Kenyan Morning", "AA Kiambu · Kenya", an element with `aria-label` "5 of 5 beans", "LIGHT", "Bright and juicy" and "28 Oct 2026", and the method icon's `svgIcon` is `pour-over` (R2).
2. `BeanRating` with value 3 renders 3 `bean-fill` and 2 `bean` icons and the label "3 of 5 beans".
3. Given `highlighted` true, then the card has the class `brew-card-highlight`.

**Negative**
4. Given notes `null`, then the card shows "No tasting notes" (R2).
5. Given a custom method with `iconKey` `cup`, then the icon's `svgIcon` is `cup` (B22).
