## Files that change
- create `frontend/src/styles/tokens.css` and `frontend/.prettierignore`: as UI implementation and Repository and tooling say.
- create `frontend/src/styles/_theme-colors.scss`: run the schematic command of "Palettes and system colours" in `frontend/`, exactly as written, once; `git add` its output; `npm run format`; commit. Never edit it by hand.
- create `frontend/src/styles/theme.scss`, in this order:
  1. `@use '@angular/material' as mat;`, `@use './theme-colors';`
  2. one `html { }` rule: `mat.theme` and `mat.theme-overrides` ("Palettes and system colours"), then the button, icon-button and fab overrides ("Button overrides"), then the other `mat.*-overrides` of the first bullet.
  3. top-level `.btn-accent`, `.btn-danger`, `.btn-on-scrim` (each one `mat.button-overrides`) and `.btn-secondary` (plain CSS), as "Variant classes" lists.
  - No other button class, no button `:hover` rule, never `::ng-deep`.
- create `frontend/src/styles/base.scss`: the global base rules of `components.css` (body, focus ring, `.sr-only`, reduced motion) and its lines 76–77 (`.spinner`, `@keyframes spin`). Nothing from lines 44–75.
- modify `frontend/src/styles.scss`: include tokens.css, theme.scss, base.scss in that order.
- modify `frontend/src/index.html`: `<title>Brewlog</title>` and the font tags of `design/prototype/index.html` lines 3–5.

## Tests that prove it
No unit seam (global styles): checked by the build and in the running app.

**Happy path**
1. `npm run build` compiles `theme.scss` (an unknown override key fails it).
2. `npm start`, browser console, `getComputedStyle(document.documentElement).getPropertyValue(name).trim()`: `--mat-sys-primary` → `#2b1d16`, `--mat-sys-tertiary` → `#b4532a`, `--mat-sys-surface` → `#fffdf8`, `--mat-sys-background` → `#f7f2e9`, `--mat-button-filled-container-height` → `44px`.

**Negative**
3. `#6d5a51` for primary or `#9e421a` for tertiary means the overrides are missing or come before `mat.theme`: not done.
4. After `npm run format`, before staging again, `git diff -w -- src/styles/_theme-colors.scss` prints nothing, and `.prettierignore` still holds only its one line.
