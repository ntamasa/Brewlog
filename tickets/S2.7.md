**Goal:** Keep the current page an espresso circle with its ivory number while the pointer is over it, as the prototype does: the hover tint applies only to enabled pages that aren't the current one.

**Source (review of PR #4, round 2):**
- `design/screens/brews.md` Layout 6: "pagination right: ‹ 1 2 3 4 › with the current page as an espresso circle". `design/DESIGN.md` `pagination-current`: background `{colors.primary}` (#2B1D16), text `{colors.on-primary}` (#FAF6EE).
- `design/prototype/components.css` lines 179–180: `.pagination .page:hover { background: var(--color-surface-sunken); }` and `.pagination .page[aria-current="page"] { background: var(--color-primary); color: var(--color-on-primary); }`. The current-page rule outranks the hover rule (specificity 0,3,0 against 0,2,0), so in the prototype the current page stays espresso under the pointer.
- The code, `frontend/src/app/journal/pagination/pagination.scss` line 24, has `.page:hover:not(:disabled)` (0,3,0), which outranks `.page[aria-current='page']` (0,2,0). Under the pointer the current page turns `surface-sunken` (#EFE8DC) and its ivory number nearly vanishes, for example over "4" right after clicking it.
