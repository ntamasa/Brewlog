## Names and signatures
- `BREWLOG_FORM_FIELD_OPTIONS: MatFormFieldDefaultOptions = { appearance: 'outline', subscriptSizing: 'dynamic', hideRequiredMarker: true }`.
- Every spec that renders a form field provides it too, as `{ provide: MAT_FORM_FIELD_DEFAULT_OPTIONS, useValue: BREWLOG_FORM_FIELD_OPTIONS }`. TestBed doesn't load `app.config.ts`.

## Tests that prove it
**Seam:** unit (`appConfig`), component (a test host in `form-field-options.spec.ts`) · **Setup:** Vitest + TestBed. The host is `<mat-form-field><input matInput required /><mat-hint>Help</mat-hint></mat-form-field>` under `{ provide: MAT_FORM_FIELD_DEFAULT_OPTIONS, useValue: BREWLOG_FORM_FIELD_OPTIONS }`, read with `MatFormFieldHarness`. · **Mocked:** nothing

The theme and helper styles have no unit seam. `npm run build` fails on any override key Material doesn't know, and the e2e test of BREW-101 checks the styles in the browser.

**Happy path**
1. `BREWLOG_FORM_FIELD_OPTIONS` equals `{ appearance: 'outline', subscriptSizing: 'dynamic', hideRequiredMarker: true }`, and `appConfig.providers` contains `{ provide: MAT_FORM_FIELD_DEFAULT_OPTIONS, useValue: BREWLOG_FORM_FIELD_OPTIONS }`.
2. Given the host, then the field's `getAppearance()` is "outline", its `getTextHints()` is ["Help"], and its subscript wrapper has the class `mat-mdc-form-field-subscript-dynamic-size`.

**Negative**
3. Given the host with a `<mat-label>Name</mat-label>` added for this test, then the field shows no required marker: there is no `.mat-mdc-form-field-required-marker` element, although the input is `required`.
