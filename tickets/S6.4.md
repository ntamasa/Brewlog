## Names and signatures
- `List<FieldErrorDto> validate(BrewDraft draft, Long selfId)`: unchanged signature. Answers either the format errors (one or more), or exactly one of `name` `DUPLICATE` / `methodId` `METHOD_NOT_FOUND`, or none.

## Hard logic
```java
List<FieldErrorDto> errors = new ArrayList<>();
// the existing format checks, in their existing order, with no repository call among them
if (!errors.isEmpty()) return List.copyOf(errors);
if (brewRepository.existsByNameIgnoreCaseAndIdNot(draft.name, selfId == null ? -1L : selfId)) {
    return List.of(new FieldErrorDto("name", ErrorCode.DUPLICATE));
}
if (!brewMethodRepository.existsById(draft.methodId)) {
    return List.of(new FieldErrorDto("methodId", ErrorCode.METHOD_NOT_FOUND));
}
return List.of();
```
