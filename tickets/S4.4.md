**Goal:** Build the two custom form controls of the brew form: the bean rating input and the method select.

**Read first:**
- Story → Frontend, Business rules (B21, B22)
- `design/screens/brew-form.md` (Brew method, Rating; state method-open), `design/prototype/screens/brew-form.html`, `design/prototype/components.css` (`bean-rating`, select), `design/screenshots/brew-form.method-open.desktop.png`, `design/screenshots/brew-form.create.desktop.png`

## Files that change
- modify `frontend/src/app/shared/bean-rating/bean-rating.ts`, `.html`, `.scss`, `.spec.ts`: input mode.
- create `frontend/src/app/brew-form/method-select/method-select.ts` (+ `.html`, `.scss`, `.spec.ts`).

## Names and signatures
- `BeanRating`: add `mode = input<'display' | 'input'>('display')`; in input mode it implements `ControlValueAccessor` (`NG_VALUE_ACCESSOR`, value `number | null`): a radio group (`role="radiogroup"`, `aria-label` "Rating") of 5 bean radios in 44 px targets, filled up to the value; text beside: "n of 5" or "Not rated"; arrow keys move the value; `setDisabledState` disables the radios; calls `onTouched` on blur.
- `MethodSelect`: `ControlValueAccessor` for a method id (`number | null`), wrapping `mat-select` inside `mat-form-field`; `methods = input.required<BrewMethod[]>()`, shown in `methodsAz` order, each option with `MethodIcon` + name; placeholder "Choose a method". (The "+ Add new method…" and "Manage methods…" options come in the methods stories.)

## Tests that prove it
**Seam:** component · **Setup:** TestBed + Material harnesses (`MatSelectHarness`), a host with a `FormControl` · **Mocked:** HTTP (sprite)

**Happy path**
1. `BeanRating` input mode: clicking the 4th bean sets the control to 4 and shows "4 of 5" (R12).
2. With value 4, ArrowRight sets 5 and ArrowLeft then sets 4.
3. `MethodSelect` with the 7 seeded methods (+ custom "chemex"): opening it lists AeroPress, chemex, Cold Brew, Espresso, French Press, Moka Pot, Pour Over, Other; choosing "Pour Over" sets the control to 2 (B21).

**Negative**
4. `BeanRating` with value null shows "Not rated" and no filled bean; ArrowLeft at 1 stays 1, ArrowRight at 5 stays 5.
5. `MethodSelect` with value null shows "Choose a method"; disabling the control disables the select.
