**Goal:** Prove the not-found and malformed-body contract on every endpoint, and that each screen shows its generic server-error message for a 400 without field errors.

**Read first:**
- Epic → Technical design → API (errors), Backend
- Story → Acceptance criteria (R41)

## Files that change
- create `backend/src/test/java/com/brewlog/ApiErrorsIT.java`.
- modify `exception/ApiExceptionHandler.java` only if a test below fails (e.g. a malformed body must answer 400 with no `errors` property on every endpoint, never 500).
- modify `frontend/src/app/brew-form/brew-form.spec.ts`, `methods/methods-dialog/methods-dialog.spec.ts`, `journal/brew-delete-dialog/brew-delete-dialog.spec.ts` (tests only; fix the code if one fails).

## Tests that prove it
**Seam:** HTTP API (`ApiErrorsIT`) · **Setup:** `IntegrationTest` · **Mocked:** nothing

**Happy path**
1. `PATCH /api/brews/999` `{"rating":4}` and `DELETE /api/brews/999` → 404 with `"code":"BREW_NOT_FOUND"` (R41).
2. `PUT /api/methods/999` `{"name":"X"}`, `POST /api/methods/999/delete` `{"reassignments":[]}`, `GET /api/methods/999/brews` → 404 with `"code":"METHOD_NOT_FOUND"` (R41).

**Negative**
3. `POST /api/brews`, `PATCH /api/brews/<existing>`, `POST /api/methods`, `PUT /api/methods/1`, `POST /api/methods/1/delete`, each with the body `{"name": ` and `Content-Type: application/json` → 400, the JSON has no `errors` property, and nothing changes in the database (R41).

**Seam:** component · **Setup:** TestBed, real APIs · **Mocked:** HTTP
4. `BrewForm`: the POST answers 400 `{}` (no `errors`) → the banner "Couldn’t save your brew" / "The Brewlog server didn’t respond. Nothing was lost: your entry is still here, so you can try again." (R41).
5. `MethodsDialog`: the add POST answers 400 `{}` → "Couldn’t save the method. Try again." (R41).
6. `BrewDeleteDialog`: the DELETE answers 400 `{}` → "Couldn’t delete this brew" / "The server didn’t respond, so nothing was removed. Try again in a moment." (R41).
