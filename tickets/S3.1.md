## Hard logic
```html
<p class="count t-body-sm" aria-live="polite">
  @if (store.status() === 'loading') {
    <span class="skeleton" style="display:inline-block;width:72px;height:12px"></span>
  } @else if (store.status() === 'ready') {
    {{ countText() }}
  }
  <!-- error: nothing -->
</p>
```
