**Goal:** Delete a brew from the card's ⋮ menu: toast "Brew deleted" and reload on the right page.

**Read first:**
- Story → Frontend, Acceptance criteria (R27, R28), Business rules (B20, B24)
- `design/screens/brews.md` (state card-menu, Interactions), `design/prototype/screens/brews.html` (card menu), `design/screenshots/brews.card-menu.desktop.png`

## Files that change
- modify `frontend/src/app/journal/brew-card/brew-card.ts`, `.html`, `.spec.ts`: menu item "Delete brew" in error colour, output `delete = output<Brew>()`.
- modify `frontend/src/app/journal/journal-page/journal-page.ts`, `.html`, `.spec.ts`: `openDelete(brew)`.
- modify `e2e/tests/journal.spec.ts`.

## Names and signatures
- `JournalPage.openDelete(brew)`: opens `BrewDeleteDialog`; on `'deleted'`: `Toaster.show('Brew deleted')`, `store.reloadAfterDelete()`, then the URL `page` follows the store; on `'gone'`: `store.reload()` (no toast).

## Tests that prove it
**Seam:** integration (`JournalPage`) · **Setup:** TestBed, real stores, `MatDialog` real · **Mocked:** HTTP (`HttpTestingController`), `MatSnackBar` spied

**Happy path**
1. Given `/journal?page=4` with 1 brew (id 37) on page 4 of 4, when ⋮ → "Delete brew" → "Delete brew" and the DELETE is flushed 204, then the snack bar shows "Brew deleted" (4000 ms), GET `…page=4` returns 0 items, GET `…page=3` follows, and the URL has `page=3` (R27).
2. Given page 2 with 12 items, when one is deleted, then GET `…page=2` is sent again and the URL keeps `page=2` (R27).

**Negative**
3. Given the DELETE answers 404, when "Close" is clicked, then the list reloads and no snack bar opens (R28).
4. Given the dialog, when "Keep brew" is clicked, then no DELETE is sent and the list is not reloaded (R27).

**Seam:** E2E · **Setup:** compose stack, both projects, brew created through the API with `uniqueName('Delete')` and today's date · **Mocked:** nothing
5. Given `/journal`, when its card's ⋮ → "Delete brew" → "Delete brew" is used, then the toast "Brew deleted" shows and no card with that name remains after reload (R27).
