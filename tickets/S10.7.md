## Hard logic
```scss
@media (max-width: 767px) {
  .toolbar {
    grid-template-columns: minmax(0, 1fr);
  }

  /* Visually hidden but still the input's label: the declarations of .sr-only in base.scss. */
  .toolbar .field-label {
    position: absolute;
    width: 1px;
    height: 1px;
    overflow: hidden;
    clip: rect(0 0 0 0);
    white-space: nowrap;
  }
}
```
