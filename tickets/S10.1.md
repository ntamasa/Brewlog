**Goal:** Filter `GET /api/brews` by a case-insensitive name search where `%` and `_` match literally.

**Read first:**
- Epic → Technical design → API (list params), Backend; Story → Hard logic (`nameContains`)
- Story → Acceptance criteria (R5, R11), Business rules (B3, B17)

## Files that change
- create `backend/src/main/java/com/brewlog/service/BrewSpecifications.java` (`nameContains` for now).
- modify `controller/BrewQueryParams.java`: bind `q` (stripped; blank → null).
- modify `service/BrewService.java`: `list` uses `brewRepository.findAll(spec, pageable)`; `matchingCount` = the page's total, `totalCount` = `count()`.
- create `backend/src/test/java/com/brewlog/BrewSearchIT.java`, `service/BrewSpecificationsTest.java`.

## Names and signatures
- `BrewSpecifications.nameContains(String q): Specification<Brew>`: `cb.like(cb.lower(root.get("name")), "%" + escape(q.toLowerCase(Locale.ROOT)) + "%", '\\')`; null `q` → no restriction (`null` spec / `cb.conjunction()`).
- `static String escape(String s)`: `\` → `\\`, `%` → `\%`, `_` → `\_` (backslash first).

## Tests that prove it
**Seam:** HTTP API · **Setup:** `BrewSearchIT extends IntegrationTest`, `TestData` with brews "Kenyan Morning", "KENYA AA Batch", "Sunday Moka", "50% Blend", "50 Percent", "a_b", "axb" · **Mocked:** nothing

**Happy path**
1. When `GET /api/brews?q=%20%20kenya%20`, then `items` are exactly "Kenyan Morning" and "KENYA AA Batch", `matchingCount` 2, `totalCount` 7 (R5).
2. When `q=50%25` (i.e. "50%"), then only "50% Blend" (R5, B17).
3. When `q=a_b`, then only "a_b", not "axb" (B17).

**Negative**
4. When `q=%20%20%20` (only spaces), then all 7 brews are listed and `matchingCount` 7 (R5, B3).
5. When `q=panama%20natural`, then `items` [], `matchingCount` 0, `totalCount` 7, `totalPages` 0 (R11).

**Seam:** unit · **Setup:** JUnit 5 · **Mocked:** nothing
6. `escape("50%_\\x")` → `"50\\%\\_\\\\x"`.
