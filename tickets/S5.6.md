**Goal:** Make `parseApiError` total: a 400 whose `errors` has any item that isn't `{ field: string, code: string }` gives the network result instead of throwing or passing bad pairs on.

**Source (review of PR #7):** `frontend/src/app/core/api-error.ts:25` maps `(errors as ApiFieldError[])` without checking the items. An `errors` of `[null]` throws a TypeError inside the brew form's subscribe error handler, and `[{field:1}]` or `["x"]` come back as `kind: 'fields'` with non-string fields and codes. Story → Technical design → Frontend (the `core/` bullet: `parseApiError(err): {kind: 'fields'|'notFound'|'protected'|'network', fields, code}`).

## Names and signatures
- `function isApiFieldError(item: unknown): item is ApiFieldError`, not exported: true only when `item` is a non-null object whose `field` and `code` are both strings.
- 400 branch: return `NETWORK` when `errors` isn't an array, is empty, **or any item fails `isApiFieldError`**. Otherwise map each item to `{ field, code }` (extra keys are dropped, as today). No cast (`as ApiFieldError[]`) is left.

## Hard logic
```ts
if (!Array.isArray(errors) || errors.length === 0 || !errors.every(isApiFieldError)) {
  return NETWORK;
}
const fields = errors.map(({ field, code }) => ({ field, code }));
```

Tests 2–7 fail on the current code: 2 and 5 throw a TypeError (`null.field`), 3, 4, 6 and 7 return `kind: 'fields'`. Test 1 already passes on it: it guards that valid items still pass. Commit it in the red commit too. Mutation check after green: temporarily replace the `.map(...)` by `errors` itself, and test 1 fails (the extra key stays); revert.

**Seam:** unit (`parseApiError`) · **Setup:** like the existing tests in `api-error.spec.ts` (`new HttpErrorResponse({ status: 400, error: { errors: … } })`) · **Mocked:** nothing

The network result is exactly `{ kind: 'network', fields: [], code: null }`, compared with `toEqual`.

**Happy path**
1. Given a 400 with `errors` `[{ field: 'origin', code: 'TOO_LONG', extra: 1 }, { field: 'name', code: 'REQUIRED' }]`, then the result equals `{ kind: 'fields', fields: [{ field: 'origin', code: 'TOO_LONG' }, { field: 'name', code: 'REQUIRED' }], code: null }` (R15).

**Negative**
2. Given a 400 with `errors` `[null]`, then calling it doesn't throw and the result is the network result.
3. Given a 400 with `errors` `[{ field: 1 }]`, then the network result.
4. Given a 400 with `errors` `["x"]`, then the network result.
5. Given a 400 with `errors` `[{ field: 'name', code: 'REQUIRED' }, null]`, then the network result: one malformed item rejects the whole body, the valid one isn't returned.
6. Given a 400 with `errors` `[{ field: 'name' }]` (no `code`), then the network result.
7. Given a 400 with `errors` `[{ field: 'name', code: 5 }]`, then the network result.
