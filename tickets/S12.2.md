## Files that change
- modify `frontend/src/app/journal/journal-toolbar/journal-toolbar.ts`, `.html`, `.scss`, `.spec.ts`: input `methods = input.required<BrewMethod[]>()`; Method select ("All methods", then `methodsAz(methods)`), Roast select ("All roasts", "Light", "Medium", "Dark"), Min. rating select ("Any rating", "2+ beans", "3+ beans", "4+ beans", "5 beans only"), in that order between Search and Sort. - modify `frontend/src/app/journal/filter-chips/filter-chips.ts`, `.html`, `.spec.ts`: input `methods`; chips after the search chip: method name (× aria-label "Remove method filter <name>"), "<Light|Medium|Dark> roast" (× "Remove roast filter <Light|…>"), "<n>+ beans" or "5 beans only" for 5 (× "Remove minimum rating filter").

- modify `frontend/src/app/journal/journal-query.ts` (+ spec): `methodId`, `roast`, `minRating` (numbers parsed with `Number`, omitted when null); `isFiltered(query)` (BREW-118) also true for a non-null `methodId`, `roast` or `minRating`. - modify `frontend/src/app/journal/journal-page/journal-page.ts`, `.html`, `.spec.ts`: loads `MethodStore` on init and passes `methods` to toolbar and chips. Footer and pagination as before (no pagination with 1 page).
