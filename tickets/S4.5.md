## Names and signatures
- `BrewForm`: `mode = input<'create' | 'edit'>('create')`, `brew = input<Brew | null>(null)` (edit comes later), `methods = input.required<BrewMethod[]>()`, `saved = output<Brew>()`, `closed = output<void>()`.
- Typed `FormGroup<BrewFormControls>`: `name`, `beanName`, `origin`, `notes` (`FormControl<string>`, non-nullable, initial `''`), `methodId: FormControl<number | null>`, `roast: FormControl<Roast | null>`, `rating: FormControl<number | null>`, `brewDate: FormControl<Date | null>` (create: today at local midnight).
- Template: head (title "Log a brew", close `icon-button` aria-label "Close without saving"), intro "Everything is required except tasting notes.", Brew name (+ help), Bean name | Origin, `MethodSelect`, roast `mat-button-toggle-group` (Light / Medium / Dark with swatches, values `LIGHT`/`MEDIUM`/`DARK`), `BeanRating` input mode, `mat-datepicker` input (`[max]` = today) with help "Defaults to today. Change it if you’re logging an earlier brew.", notes textarea ("Optional" label, placeholder from the screen spec), foot "Cancel" + "Add to journal".
- `toBody(value): BrewBody`: strings as typed (the server trims), notes `''` → `null`, `brewDate` → `format(date, 'yyyy-MM-dd')`.
- Submit: `saving = signal(false)`; while saving the primary shows a spinner + "Saving…" with `aria-busy="true"` and the form is disabled; on success emit `saved(brew)`. Cancel and × emit `closed()` (the discard guard comes in a later story).
- On open, focus goes to Brew name (`cdkFocusInitial`).

## Tests that prove it
**Seam:** component · **Setup:** TestBed + harnesses, `vi.useFakeTimers({ toFake: ['Date'] })` with `vi.setSystemTime(new Date(2026, 10, 1, 9, 0))`, real `BrewApi` · **Mocked:** HTTP (`HttpTestingController`)

**Happy path**
1. Given create mode, then the title is "Log a brew", all text fields are empty, method/roast/rating unset, the date input shows "1 Nov 2026" and Brew name has focus (R12).
2. Given name "Kenyan Morning", bean "AA Kiambu", origin "Kenya", method Pour Over (2), roast Light, rating 5, empty notes, when "Add to journal" is clicked, then POST `/api/brews` has `{"name":"Kenyan Morning","beanName":"AA Kiambu","origin":"Kenya","methodId":2,"roast":"LIGHT","rating":5,"brewDate":"2026-11-01","notes":null}`; while unflushed the button reads "Saving…" and the inputs are disabled; flushing 201 emits `saved` with the brew (R12).

**Negative**
3. Given the datepicker, then 2 Nov 2026 is disabled and 1 Nov 2026 is enabled (B8).
4. Given the form, when "Cancel" is clicked, then `closed` emits and no request is sent.
