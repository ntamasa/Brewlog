## Hard logic
`journal-toolbar.html`, `filter-chips.html` and the `journal-page.html` addition, as run on Angular and Material 22.3.0 (with the store methods and the count below, they passed tests 8, 9 and 12, under the Fake-timer harness):
```html
<!-- journal-toolbar.html -->
<div class="toolbar" role="search">
  <div class="field">
    <label class="field-label" for="q">Search</label>
    <mat-form-field>
      <mat-icon matIconPrefix svgIcon="search" aria-hidden="true" />
      <input matInput #searchInput id="q" type="search" placeholder="Search brew names" autocomplete="off"
        [value]="query().q" (input)="searchChange.emit(searchInput.value)" />
    </mat-form-field>
  </div>
</div>

<!-- filter-chips.html -->
@if (isFiltered()) {
  <div class="chips chips-row" aria-label="Active filters">
    <span class="chip">“{{ query().q.trim() }}”<button type="button" aria-label="Clear search" (click)="remove.emit('q')"><mat-icon svgIcon="close" class="icon" aria-hidden="true" /></button></span>
    <button matButton="text" type="button" (click)="clearAll.emit()">Clear all</button>
  </div>
}

<!-- journal-page.html, between the page-head and @switch -->
@if (!isEmpty()) {
  <app-journal-toolbar [query]="store.query()" (searchChange)="store.setSearch($event)" />
  <app-filter-chips [query]="store.query()" (remove)="store.removeFilter($event)" (clearAll)="store.clearFilters()" />
}
```
