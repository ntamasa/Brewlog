## Names and signatures
- `confirmingDiscard = signal(false)`. While true, the foot shows `<p #discardText class="discard-text" tabindex="-1">Discard changes?</p>`, `<button matButton="outlined" type="button" class="btn-secondary">` "Keep editing" (`keepEditing()`) and `<button matButton="filled" type="button">` "Discard" (`discard()`: emits `closed`, nothing is sent; no extra class) in place of Cancel and the primary, in the same layout (the prototype has no markup for this prompt). That is the button mapping of UI implementation's "Buttons are Material" bullet, in BREW-87 (button-secondary → `matButton="outlined" class="btn-secondary"`, button-primary → `matButton="filled"`), the same markup as the current Cancel and "Add to journal" in `brew-form.html`. There is no `button-primary` or `button-secondary` class in the app.
- `BrewForm.requestClose(): void`: does nothing while the prompt is open; emits `closed` if `form.dirty` is false; otherwise remembers where focus is, opens the prompt and focuses `#discardText` (Hard logic).
- `keepEditing(): void`: hides the prompt and, after the foot has rendered again, focuses the remembered target (Hard logic).
- Cancel (`#cancelButton`, `cancelButton = viewChild<ElementRef<HTMLButtonElement>>('cancelButton')`), × "Close without saving" and Esc (`host: { '(keydown.escape)': 'requestClose()' }`) all call `requestClose()`. `MethodSelect` already stops the Esc that closes its open listbox (BREW-109), so that Esc never reaches the host.
- `BrewForm` injects `ElementRef<HTMLElement>` as `host` to test "inside the form".

## Hard logic
```ts
private returnTo: HTMLElement | 'cancel' = 'cancel';

requestClose(): void {
  if (this.confirmingDiscard()) return;
  if (!this.form.dirty) {
    this.closed.emit();
    return;
  }
  const active = document.activeElement;
  this.returnTo =
    active instanceof HTMLElement &&
    active !== this.cancelButton()?.nativeElement &&
    this.host.nativeElement.contains(active)
      ? active // ×, a field
      : 'cancel'; // Cancel itself (removed by the prompt), or outside the form (backdrop click)
  this.confirmingDiscard.set(true);
  afterNextRender(() => this.discardText()?.nativeElement.focus(), { injector: this.injector });
}

keepEditing(): void {
  const target = this.returnTo;
  this.confirmingDiscard.set(false);
  afterNextRender(
    () => {
      const stillInside = target !== 'cancel' && this.host.nativeElement.contains(target);
      (stillInside ? target : this.cancelButton()?.nativeElement)?.focus(); // the re-rendered Cancel
    },
    { injector: this.injector },
  );
}
```
