**Goal:** Ask "Discard changes?" in the form foot before closing a form with changes.

**Read first:**
- Story → Frontend, Acceptance criteria (R21)
- `design/screens/brew-form.md` (Interactions: Cancel / close), `design/prototype/screens/brew-form.html` (foot), `design/screenshots/brew-form.create.desktop.png`, `design/screenshots/brew-form.edit.desktop.png`

## Files that change
- modify `frontend/src/app/brew-form/brew-form.ts`, `.html`, `.scss`, `.spec.ts`.
- modify `frontend/src/app/journal/journal-page/journal-page.ts`, `.html`: the sidenav has `disableClose`; its backdrop click and Esc call `BrewForm.requestClose()` instead of closing directly.

## Names and signatures
- `BrewForm.requestClose(): void`: if `form.dirty` → `confirmingDiscard.set(true)`; else emit `closed`.
- `confirmingDiscard = signal(false)`: the foot shows "Discard changes?" with `button-secondary` "Keep editing" (sets it false, focus back to the form) and `button-primary` "Discard" (the prototype has no markup for this prompt; it replaces the foot's two buttons in the same layout) (emits `closed`, nothing is sent).
- Cancel, × and Esc (`keydown.escape` on the form host) all call `requestClose()`.

## Tests that prove it
**Seam:** component · **Setup:** TestBed + harnesses · **Mocked:** HTTP

**Happy path**
1. Given the name changed to "K", when "Cancel" is clicked, then the foot shows "Discard changes?", "Keep editing" and "Discard", and `closed` has not emitted (R21).
2. Given that prompt, when "Discard" is clicked, then `closed` emits and no request is sent (R21).
3. Given that prompt, when "Keep editing" is clicked, then the prompt disappears and the name still reads "K" (R21).

**Negative**
4. Given an untouched create form, when ×, Cancel or Esc is used, then `closed` emits at once without the prompt (R21).
5. Given a changed rating, when Esc is pressed, then the prompt shows (R21).

**Seam:** integration (`JournalPage`) · **Setup:** TestBed, real stores · **Mocked:** HTTP
6. Given the form open with a changed origin, when the sidenav backdrop is clicked, then the sidenav stays open with "Discard changes?" (R21).

## Out of scope
- The brew-gone "Close", which closes without asking (story "Edit a brew").
