## Names and signatures
- `MethodApi.create(name: string): Observable<BrewMethod>` → POST `/api/methods` `{ name }`.
- `MethodStore.add(name: string): Observable<BrewMethod>`: calls the API; on success appends the method to `methods` and returns it; errors pass through to the caller.
- `methodsDialogOrder(methods)`: non-protected predefined by `position`, then custom (`predefined` false) A–Z ignoring case, then protected.
- `checkMethodName(name: string, methods: BrewMethod[], selfId: number | null): { code: 'REQUIRED' | 'TOO_LONG' | 'DUPLICATE'; existing?: string } | null`: trims; empty → REQUIRED; > 50 → TOO_LONG; another method (id ≠ selfId) with the same name ignoring case → DUPLICATE with `existing` = that method's name.
- `methodNameMessage(code: string, existing: string | null, place: 'dialog' | 'form'): string`: REQUIRED "Enter a method name"; TOO_LONG "Method name can be at most 50 characters"; DUPLICATE dialog "“<existing>” already exists. Method names must be unique.", form "“<existing>” already exists."; anything else (network) "Couldn’t save the method. Try again."

## Tests that prove it
**Seam:** unit · **Setup:** Vitest + TestBed, `HttpTestingController`; store with a fake `MethodApi` · **Mocked:** HTTP / API

**Happy path**
1. `methodsDialogOrder` of the API order (AeroPress, chemex, Cold Brew, Espresso, French Press, Moka Pot, Pour Over, Other) → Espresso, Pour Over, French Press, AeroPress, Moka Pot, Cold Brew, chemex, Other (R29, B21).
2. `MethodApi.create('Chemex')` sends POST `/api/methods` with `{"name":"Chemex"}` (R30).
3. `MethodStore.add('Chemex')` with the fake answering Chemex (id 8) → `methods` contains Chemex (R30).
4. `checkMethodName(' Chemex ', seeded, null)` → null; 50 characters → null (R30).

**Negative**
5. `checkMethodName('   ', …)` → REQUIRED; 51 characters → TOO_LONG; `'pour over'` → DUPLICATE with `existing` "Pour Over"; `'Pour Over'` with `selfId` 2 → null (R30, B12).
6. `methodNameMessage('DUPLICATE', 'Pour Over', 'dialog')` → "“Pour Over” already exists. Method names must be unique."; `'form'` → "“Pour Over” already exists."; `methodNameMessage('NETWORK', null, 'dialog')` → "Couldn’t save the method. Try again." (R30).
7. `MethodStore.add` with the fake erroring → `methods` unchanged and the error is re-emitted.
