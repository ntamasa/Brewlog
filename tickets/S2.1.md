**Goal:** Serve the first page of brews, newest first, from `GET /api/brews`.

**Read first:**
- Epic → Technical design → Data model, API, Backend, Hard logic (sort NEWEST)
- Story → Seams and tests, Acceptance criteria (R2), Business rules (B19, B20)

## Files that change
- create `backend/src/main/java/com/brewlog/entity/Roast.java`, `entity/BrewMethod.java`, `entity/Brew.java` (JPA mappings of Epic → Data model; `Brew.method` is `@ManyToOne(fetch = LAZY)`; `createdAt` is `Instant`, `insertable = false, updatable = false`, read back with `@Generated` so the DB default applies).
- create `repository/BrewRepository.java`, `repository/BrewMethodRepository.java` with the methods of Epic → Backend (add the query methods now, use only what this subtask needs).
- create `dto/BrewResponse.java`, `dto/MethodRef.java`, `dto/BrewPage.java`, `dto/BrewQuery.java`, `dto/SortKey.java`.
- create `service/BrewSort.java`, `service/BrewService.java` (only `list` for now).
- create `controller/BrewController.java`, `controller/BrewQueryParams.java` (binds `page`, default 1; the other params come in later stories).
- create `backend/src/test/java/com/brewlog/support/TestData.java`, `BrewListIT.java`, `service/BrewSortTest.java`.

## Names and signatures
- `record BrewResponse(long id, String name, String beanName, String origin, MethodRef method, Roast roast, int rating, LocalDate brewDate, String notes)`; `record MethodRef(long id, String name, String iconKey)`
- `record BrewPage(List<BrewResponse> items, int page, int totalPages, long matchingCount, long totalCount)`
- `record BrewQuery(String q, Long methodId, Roast roast, Integer minRating, SortKey sort, int page)`; `enum SortKey { NEWEST, OLDEST, HIGHEST, LOWEST }`
- `BrewSort.toSort(SortKey key): Sort`: only `NEWEST` = `brewDate desc, createdAt desc, id desc` for now; other keys throw `UnsupportedOperationException` until the sort story.
- `BrewService.list(BrewQuery query): BrewPage`: page size 12, `PageRequest.of(page - 1, 12, BrewSort.toSort(sort))`, `totalPages = ceil(matchingCount / 12)` (0 when there are none), `totalCount = brewRepository.count()`.
- `GET /api/brews` → `BrewController.list(BrewQueryParams params): BrewPage`
- `TestData.brew(String name)` builder with `.bean(..)`, `.origin(..)`, `.method(long id)`, `.roast(String)`, `.rating(int)`, `.date(String isoDate)`, `.createdAt(String isoInstant)`, `.notes(String)`, `.insert(JdbcTemplate jdbc): long` (defaults: bean "AA Kiambu", origin "Kenya", method 1, roast `MEDIUM`, rating 3, date 2026-10-01, `createdAt` = DB default).

## Tests that prove it
**Seam:** HTTP API · **Setup:** `BrewListIT extends IntegrationTest`, data via `TestData` · **Mocked:** nothing

**Happy path**
1. Given 41 brews with distinct dates, when `GET /api/brews`, then 200 with 12 `items` (the 12 latest dates, latest first), `page` 1, `totalPages` 4, `matchingCount` 41, `totalCount` 41 (R2).
2. Given those 41 brews, when `GET /api/brews?page=4`, then 5 items, the 5 earliest dates, latest of them first (R2).
3. Given a brew "Kenyan Morning" (bean "AA Kiambu", origin "Kenya", Pour Over = method 2, `LIGHT`, 5, 2026-10-28, notes "Bright"), then its item is exactly `{"id":…, "name":"Kenyan Morning", "beanName":"AA Kiambu", "origin":"Kenya", "method":{"id":2,"name":"Pour Over","iconKey":"pour-over"}, "roast":"LIGHT", "rating":5, "brewDate":"2026-10-28", "notes":"Bright"}` (R2).
4. Given A and B both on 2026-11-01 with B's `createdAt` later, when listing, then B comes before A (B19).

**Negative**
5. Given 0 brews, when `GET /api/brews`, then 200 `{"items":[], "page":1, "totalPages":0, "matchingCount":0, "totalCount":0}`.
6. Given a brew without notes, then its item has `"notes": null` (the key is present).

**Seam:** unit · **Setup:** JUnit 5 · **Mocked:** nothing
7. `BrewSort.toSort(NEWEST)` equals `Sort.by(desc("brewDate"), desc("createdAt"), desc("id"))`.
