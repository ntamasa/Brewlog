## Names and signatures
- `BrewDetailDialog` (opened with `MatDialog.open(BrewDetailDialog, { data: { brew }, width: '640px', autoFocus: '[cdkFocusInitial]' })`, `restoreFocus` at its default, true): method icon + name, brew name, "Bean · Origin", facts Rating ("n of 5"), Roast ("Light"/"Medium"/"Dark"), Method, Brewed on (`formatDate`), notes with `white-space: pre-line`, or muted "No tasting notes yet. Edit this brew to add some."; ghost "Delete" (closes with `'delete'`), primary "Edit brew" (closes with `'edit'`), close `icon-button` × (aria-label "Close", carries the attribute `cdkFocusInitial`, the dialog's only one; closes with `undefined`). The dialog moves no focus itself and uses no `cdkTrapFocus`: `MatDialog` focuses × on open and returns focus to the card's name button on close (R47, R26).
- `JournalPage.openDetail(brew)`: on `'edit'` → `openEdit(brew)`; on `'delete'` → `openDelete(brew)`.
