**Goal:** Put the shared helpers of components.css once into the global helpers.scss, so no component SCSS copies them.

**Read first:** Technical design → UI implementation, below: "Shared helpers", "Component SCSS", "Style budgets".

## Files that change
- create `frontend/src/styles/helpers.scss`: the rules "Shared helpers" lists, in components.css order, declarations unchanged; only the icon selectors change, to the `.mat-icon` forms listed there. Nothing else from components.css.
- modify `frontend/src/styles.scss`: `@use './styles/helpers';` as its last line.

## Tests that prove it
No unit seam (global styles): checked by the build, grep in frontend/ and the running app.

**Happy path**
1. `npm run build` passes with no budget warning or error.
2. `npm start`, browser console, `getComputedStyle` of an element appended to the body: class t-caps → textTransform "uppercase"; classes "mat-icon icon-sm" → width "16px"; class container at 390 px → paddingLeft "16px", at 1440 px "48px".

**Negative**
3. `grep -nE '^\s*\.(icon|bean|brand-mark)\b' src/styles/helpers.scss` prints nothing: every icon size keeps its .mat-icon prefix.
4. helpers.scss has no button or spinner rule, and angular.json is unchanged.

## Out of scope
- Every component SCSS, the landing's included (next subtask).

## Done when
- `cd frontend && npm run lint && npm run format:check && npm test && npm run build` passes, and checks 2–4 hold.
