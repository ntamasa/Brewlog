**Goal:** Rename a method with `PUT /api/methods/{id}`, with the name rules, not-found and the protected "Other".

**Read first:**
- Epic → Technical design → API, Backend
- Story → Acceptance criteria (R24, R32), Business rules (B5, B11, B12, B13)

## Files that change
- modify `backend/src/main/java/com/brewlog/entity/BrewMethod.java`: add `setName` below, its only setter (nothing else on a method ever changes).
- create `exception/ProtectedMethodException.java`.
- modify `exception/ApiExceptionHandler.java`: `ProtectedMethodException` → `ProblemDetail.forStatus(409)` with `code` `"PROTECTED"`.
- modify `service/BrewMethodService.java`: `rename`; `controller/BrewMethodController.java`: `PUT /api/methods/{id}`.
- create `backend/src/test/java/com/brewlog/MethodRenameIT.java`.

## Names and signatures
- `public void setName(String name)` on `BrewMethod`.
- `BrewMethodService.rename(long id, String name): MethodResponse`, `@Transactional`: missing → `NotFoundException(METHOD_NOT_FOUND)`; `isProtected` → `ProtectedMethodException`; then `String stripped = validateName(name, id)`; `method.setName(stripped)` (icon key, `predefined` and `position` stay), `brewMethodRepository.saveAndFlush(method)`, return it with its `brewCount` (`brewRepository.countByMethodId(id)`).

## Tests that prove it
**Seam:** HTTP API · **Setup:** `MethodRenameIT extends IntegrationTest`, `TestData` · **Mocked:** nothing

**Happy path**
1. Given custom "Chemex" (0 brews), PUT `{"name":"Chemex Classic"}` → 200 with name "Chemex Classic", `brewCount` 0 (R32).
2. Given Pour Over with 2 brews, PUT `{"name":"Pour Over (V60)"}` → 200, `iconKey` "pour-over", `position` 2, `predefined` true; `GET /api/brews` shows `method.name` "Pour Over (V60)" on both brews (B13, B22).
3. Given custom "moka", PUT `{"name":"Moka"}` → 200 "Moka" (R24).
4. Given brew "kenyan morning", PATCH `/api/brews/<id>` `{"name":"Kenyan Morning"}` → 200 with "Kenyan Morning" (R24).

**Negative**
5. PUT `{"name":"  "}` → 400 `name` `REQUIRED`; 51 characters → `TOO_LONG`; Chemex renamed to "espresso" → `DUPLICATE`; the name stays "Chemex" (R32).
6. PUT on Other (id 7) `{"name":"Misc"}` → 409 `"code": "PROTECTED"`, name still "Other" (B11).
7. PUT `/api/methods/999` → 404 `"code": "METHOD_NOT_FOUND"`.
