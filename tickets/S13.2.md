**Goal:** Clean invalid URL params before loading, and move to the last page when the URL asks for a page past it.

**Read first:**
- Story → Frontend, Acceptance criteria (R8, R9, R10), Business rules (B18, B20)

## Files that change
- modify `frontend/src/app/journal/journal-query.ts` (+ spec): strict parsing and `sanitizeQuery`.
- modify `frontend/src/app/journal/journal.store.ts` (+ spec): page-past-last handling.

## Names and signatures
- `queryFromParams(params: ParamMap): { query: BrewQuery; dropped: string[] }`: a param that doesn't parse is reset to its default and its name added to `dropped`: `roast` not `LIGHT`/`MEDIUM`/`DARK`; `minRating` not an integer 2–5; `sort` not a `SortKey`; `page` not an integer ≥ 1; `methodId` not a positive integer. (Update the callers of the old signature.)
- `sanitizeQuery(query: BrewQuery, methods: BrewMethod[]): { query: BrewQuery; dropped: string[] }`: `methodId` not among `methods` ids → `null`, `dropped` `['methodId']`.
- `JournalStore.load`: when the answer has `items.length === 0`, `page > totalPages` and `totalPages >= 1`, it loads `page = totalPages` once more (the query's `page` becomes `totalPages`).

## Tests that prove it
**Seam:** unit · **Setup:** Vitest, `convertToParamMap`; store with a fake `BrewApi` · **Mocked:** API

**Happy path**
1. `queryFromParams(q=kenya&roast=LIGHT&minRating=4&sort=HIGHEST&page=2)` → those values and `dropped` [] (R8).
2. Given the fake API answering `page=9` with `{items: [], page: 9, totalPages: 4, matchingCount: 41, totalCount: 41}`, when `setQuery({...DEFAULT_QUERY, page: 9})`, then a second call is made with `page: 4` and `query().page` is 4 (R10).

**Negative**
3. `queryFromParams(roast=FOO&methodId=9)` → `roast` null, `methodId` 9, `dropped` `['roast']`; then `sanitizeQuery` with the 7 seeded methods → `methodId` null, `dropped` `['methodId']` (R9).
4. `queryFromParams` of `minRating=1`, `minRating=7`, `sort=X`, `page=0`, `methodId=abc` each → default value and that name in `dropped` (R9).
5. Given an answer with 0 items, page 1 and `totalPages` 0, then no second call is made (R10).
