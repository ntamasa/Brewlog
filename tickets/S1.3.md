**Goal:** Build the landing page exactly as the design shows it.

**Read first:**
- Story → Acceptance criteria (R1)
- `design/DESIGN.md`, `design/screens/landing.md`, `design/prototype/screens/landing.html`, `design/prototype/components.css`, `design/screenshots/landing.default.desktop.png`, `design/screenshots/landing.default.mobile.png`

## Files that change
- modify `frontend/src/app/landing/landing-page/landing-page.ts`, `.html`, `.scss`: markup and copy from `landing.html`, styles from its `<style>` block and the matching parts of `components.css`, including their media queries. Images from `images/*.jpg`, icons as `<mat-icon svgIcon="…">`.

## Names and signatures
- Brand mark: `routerLink="/"`. Nav "Open journal →", hero "Open my journal" and closing "Open my journal →": `routerLink="/journal"`. "How it works": `routerLink="/"` with `fragment="how"`. The steps section has `id="how"`.

## Tests that prove it
**Seam:** component · **Setup:** TestBed, `provideRouter(routes)`, `RouterTestingHarness`, `provideHttpClient()` + `provideHttpClientTesting()` (sprite request left unflushed) · **Mocked:** HTTP

**Happy path**
1. Given `/` is rendered, then it contains the texts "Remember every cup worth remembering.", "A ledger for the cups you love.", "Brew. Log. Rediscover." and "Your next great cup starts with the last one." (R1).
2. Given `/`, then three `img` elements have `src` ending in `hero-pour-over.jpg`, `beans.jpg` and `cup-notebook.jpg`, each with a non-empty `alt`, and the footer contains the three photo credits from `landing.html` (R1).
3. Given `/`, when the hero "Open my journal" is clicked, then the URL is `/journal`; the same for the nav "Open journal →" and the closing "Open my journal →" (R1).
4. Given `/`, when "How it works" is clicked, then the URL is `/#how` and an element with `id="how"` exists (R1).

**Negative**
5. Given the page scrolled down, when the brand mark is clicked, then the URL stays `/` with no fragment (R1).

## Out of scope
- Verifying the 390 px layout (story "Use Brewlog on a phone"); the ported CSS still keeps the prototype's media queries.

## Done when
- `cd frontend && npm run lint && npm run format:check && npm test && npm run build` passes, and `npm start` matches `landing.default.desktop.png`.
