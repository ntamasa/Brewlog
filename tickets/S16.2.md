## Names and signatures
- `MethodApi.rename(id: number, name: string): Observable<BrewMethod>` → PUT `/api/methods/{id}` `{ name }`.
- `MethodStore.rename(id, name): Observable<BrewMethod>`: on success replaces that method in `methods`.
- Dialog: each non-protected row gets a pencil `icon-button` (aria-label "Rename <name>"); `renamingId = signal<number | null>(null)`; the row turns ivory with a focused input holding the current name, ghost "Cancel" + primary "Save". Enter / "Save": `checkMethodName(value, methods, id)` → message under the row input (`'dialog'` texts), nothing sent; else `MethodStore.rename`; success: row back to normal with the new name, `Toaster.show('Renamed to “' + name + '”')`, `JournalStore.reload()` (cards show the new name); 400 → matching message; network → "Couldn’t save the method. Try again.". Esc / "Cancel": leave the row unchanged, focus back on the pencil.
- For now every valid rename saves directly; the next story adds the confirmation step for methods with brews.

## Tests that prove it
**Seam:** integration (`MethodsDialog`) · **Setup:** TestBed, real `MethodStore`, `MethodApi`, `JournalStore` · **Mocked:** HTTP (`HttpTestingController`), `MatSnackBar` spied

**Happy path**
1. Given "Chemex" (0 brews), when its pencil is clicked, "Chemex Classic" typed and Enter pressed, then PUT `/api/methods/8` `{"name":"Chemex Classic"}`; after 200 the row reads "Chemex Classic" and the snack bar shows "Renamed to “Chemex Classic”" (R32).
2. Given "moka" (custom), when renamed to "Moka", then the PUT is sent (no duplicate error with itself) (R24).

**Negative**
3. Given the rename input, when Esc is pressed or "Cancel" clicked, then no request is sent and the row still reads "Chemex" (R32).
4. When the input is emptied → "Enter a method name"; 51 characters → "Method name can be at most 50 characters"; "espresso" → "“Espresso” already exists. Method names must be unique."; in each case nothing is sent (R32).
5. Given the PUT answers 503, then "Couldn’t save the method. Try again." shows under the row input, which keeps "Chemex Classic" (R32).
6. Given "Other", then it has no pencil (B11).
