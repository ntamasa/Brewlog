**Goal:** Add the frontend models, the brews API client, the formatting helpers and the journal store that loads a page of brews.

**Read first:**
- Epic → Technical design → API
- Story → Frontend, Acceptance criteria (R2), Business rules (B20, B23)

## Files that change
- create `frontend/src/app/core/models.ts`, `core/brew-api.ts`, `core/format.ts` (+ `.spec.ts` for the last two).
- create `frontend/src/app/journal/journal.store.ts` (+ `journal.store.spec.ts`), `journal/journal-query.ts` (+ spec).

## Names and signatures
- `models.ts`: `type Roast = 'LIGHT' | 'MEDIUM' | 'DARK'`; `type SortKey = 'NEWEST' | 'OLDEST' | 'HIGHEST' | 'LOWEST'`; `interface MethodRef { id: number; name: string; iconKey: string }`; `interface Brew { id; name; beanName; origin; method: MethodRef; roast: Roast; rating: number; brewDate: string; notes: string | null }`; `interface BrewMethod { id; name; iconKey; predefined: boolean; protected: boolean; position: number | null; brewCount: number }`; `interface BrewPage { items: Brew[]; page; totalPages; matchingCount; totalCount }`; `interface BrewQuery { q: string; methodId: number | null; roast: Roast | null; minRating: number | null; sort: SortKey; page: number }`; `const DEFAULT_QUERY: BrewQuery = { q: '', methodId: null, roast: null, minRating: null, sort: 'NEWEST', page: 1 }`; `interface ApiFieldError { field: string; code: string }`.
- `BrewApi` (`@Injectable({ providedIn: 'root' })`): `list(query: BrewQuery): Observable<BrewPage>`: GET `/api/brews` with `sort` and `page` always, `q` only when `q.trim()` is not empty (sent trimmed), `methodId`, `roast`, `minRating` only when not null.
- `format.ts`: `formatDate(iso: string): string` → `"28 Oct 2026"` (date-fns `format(parseISO(iso), 'd MMM yyyy')`); `brewCount(n: number): string` → `"1 brew"` / `"n brews"`.
- `journal-query.ts`: `queryFromParams(params: ParamMap): BrewQuery` and `queryToParams(query: BrewQuery): Params`; for now only `page` (omitted when 1; a missing or non-numeric value gives 1).
- `JournalStore` (`signalStore({ providedIn: 'root' })`): state `query: BrewQuery`, `items: Brew[]`, `page`, `totalPages`, `matchingCount`, `totalCount`, `status: 'loading' | 'ready' | 'error'`, `highlightId: number | null`; methods `setQuery(query: BrewQuery)` (sets it and loads), `setPage(page: number)` (loads that page), `reload()` (same query again); `load` is an `rxMethod<BrewQuery>` with `switchMap` to `BrewApi.list`, setting `status` `loading` before and `ready` after, copying the page fields.

## Tests that prove it
**Seam:** unit · **Setup:** Vitest + TestBed, `provideHttpClient()`, `provideHttpClientTesting()` · **Mocked:** HTTP (`HttpTestingController`); the store gets a fake `BrewApi`

**Happy path**
1. `BrewApi.list(DEFAULT_QUERY)` sends GET `/api/brews?sort=NEWEST&page=1` and emits the flushed body (R2).
2. `BrewApi.list({...DEFAULT_QUERY, q: '  kenya ', methodId: 2, roast: 'LIGHT', minRating: 4, sort: 'HIGHEST', page: 2})` sends `q=kenya&methodId=2&roast=LIGHT&minRating=4&sort=HIGHEST&page=2`.
3. `formatDate('2026-10-28')` → `"28 Oct 2026"`; `formatDate('2026-11-01')` → `"1 Nov 2026"` (R2).
4. `brewCount(41)` → `"41 brews"`, `brewCount(1)` → `"1 brew"`, `brewCount(0)` → `"0 brews"` (B23).
5. Given a fake API answering `{items: 12 brews, page: 1, totalPages: 4, matchingCount: 41, totalCount: 41}`, when `setQuery(DEFAULT_QUERY)`, then `status` goes `loading` → `ready` and the store holds those values (R2).
6. When `setPage(3)`, then the fake API is called with `page: 3` and `query().page` is 3.
7. `queryFromParams` of `?page=2` gives `page: 2`; `queryToParams({...DEFAULT_QUERY, page: 2})` gives `{ page: 2 }`.

**Negative**
8. `BrewApi.list({...DEFAULT_QUERY, q: '   '})` sends no `q` param.
9. `queryFromParams` of `?page=abc` and of no params both give `page: 1`; `queryToParams(DEFAULT_QUERY)` gives `{}`.
