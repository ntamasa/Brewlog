  - add the top-level block `permissions:` / `  contents: read` between `on:` and `jobs:`.
  - steps, each starting with `- name:`: "Check out code" (`uses: actions/checkout@v4`), "Setup Java JDK" (`uses: actions/setup-java@v4`, its `with:` unchanged), "Check formatting" (`run: ./gradlew spotlessCheck`), "Run tests" (`run: ./gradlew test`). The single `./gradlew spotlessCheck test` step is gone.
  - `on:` with its two paths and `defaults.run.working-directory: backend` stay as they are.
- modify `.github/workflows/frontend.yml`:
  - the same `permissions:` / `contents: read` block.
  - steps in this order: "Check out code" (`actions/checkout@v4`), "Setup Node.js" (`actions/setup-node@v4`, its `with:` unchanged: `node-version-file: .nvmrc`, `cache: npm`, `cache-dependency-path: frontend/package-lock.json`), "Install dependencies" (`npm ci`), "Audit dependencies" (`npm audit --audit-level=moderate`), "Lint" (`npm run lint`), "Check formatting" (`npm run format:check`), "Run tests" (`npm test`), "Build" (`npm run build`).
  - `on:` with its two paths and `defaults.run.working-directory: frontend` stay.
- modify `.github/workflows/e2e.yml`:
  - the same `permissions:` / `contents: read` block.
  - `on.pull_request.paths` exactly these 7, in this order: `backend/**`, `.github/workflows/backend.yml`, `frontend/**`, `.github/workflows/frontend.yml`, `e2e/**`, `docker-compose.yml`, `.github/workflows/e2e.yml`.
  - steps in this order: "Check out code" (`actions/checkout@v4`), "Reset the stack" (`docker compose down -v`), "Start the stack" (`docker compose up -d --build --wait`), "Setup Node.js" (`actions/setup-node@v4` with `node-version-file: .nvmrc`), "Install dependencies" (`npm ci`), "Audit dependencies" (`npm audit --audit-level=moderate`), "Install Playwright browser" (`npx playwright install --with-deps chromium`), "Run e2e tests" (`npx playwright test`); the last four each with `working-directory: e2e`.
- modify `.github/workflows/factory-merge-gate.yml`: its single step becomes `- name: Run merge gate` followed by `uses: actions/github-script@v7` (same indentation as `with:`). Nothing else in the file changes, not even its header comment.
- modify `frontend/package.json`: `devDependencies` `"typescript-eslint": "8.74.0"` (was `8.72.2`; exact, no `^` or `~`). Then run `npm install` in `frontend/` so `frontend/package-lock.json` follows (commit it). No other dependency changes, and never `npm audit fix` (it would move other packages).
- `e2e/package.json` and `e2e/package-lock.json` don't change: `npm audit` there already reports 0.

## Tests that prove it
**Seam 1:** dependency audit · **Setup:** `npm ci` in `frontend/` and in `e2e/` · **Mocked:** nothing

**Happy path**
1. Given the updated lock, when `npm audit --audit-level=moderate` runs in `frontend/`, then it prints `found 0 vulnerabilities` and exits 0. The same in `e2e/`.
2. Given the updated lock, when `npm ls typescript-eslint` runs in `frontend/`, then it shows `typescript-eslint@8.74.0`, and `npm ls @typescript-eslint/typescript-estree --all` shows no version other than `8.74.0`.

**Negative**
3. Given the old pin `8.72.2`, `npm audit` in `frontend/` reports 7 moderate vulnerabilities (minimatch, GHSA-g3hv-75wg-m249, through `@typescript-eslint/typescript-estree` ≤ 8.72.2) and exits 1: that is what the new "Audit dependencies" step fails a PR on. After this change it reports none (test 1).

**Seam 2:** workflow files, from the repo root · **Setup:** none · **Mocked:** nothing

**Happy path**

For `frontend.yml`: Check out code, Setup Node.js, Install dependencies, Audit dependencies, Lint, Check formatting, Run tests, Build. For `e2e.yml`: Check out code, Reset the stack, Start the stack, Setup Node.js, Install dependencies, Audit dependencies, Install Playwright browser, Run e2e tests. For `factory-merge-gate.yml`: only Run merge gate.

6. `e2e.yml`'s `paths:` list is exactly the 7 entries above, in that order.

**Negative**
7. `grep -nE '^\s*- (uses|run):' .github/workflows/*.yml` prints nothing: no step without a name is left.
8. Before committing, `git diff -- .github/workflows/factory-merge-gate.yml` shows exactly one removed line (`- uses: actions/github-script@v7`) and two added lines (`- name: Run merge gate`, `uses: actions/github-script@v7`), and `git diff` shows no change to the `paths:` of `backend.yml` and `frontend.yml`.
