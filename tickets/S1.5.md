- create `frontend/Dockerfile`: stage 1 `node:24` runs `npm ci` and `npm run build`; stage 2 `nginx:1.29-alpine` copies `dist/frontend/browser` to `/usr/share/nginx/html` and `nginx.conf` to `/etc/nginx/conf.d/default.conf`. Add `frontend/.dockerignore` (`node_modules`, `dist`, `.angular`).

**E2E rule for every later story:** tests run against one shared database in both projects, so every test creates its own data with `uniqueName(...)` names through the API (`request.post('/api/...')`) and scopes its assertions to that data (e.g. by searching for the unique prefix). Never assume an empty database.
