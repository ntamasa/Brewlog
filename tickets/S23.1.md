**Goal:** Truncate the desktop pagination beyond 7 pages: first, last, current ±1 and a non-clickable "…" per gap, never hiding a single page behind "…".

## Names and signatures
- `export function pageItems(page: number, totalPages: number): (number | 'gap')[]`.
- In `Pagination` (desktop): a number renders as the page button it is today; `'gap'` renders `<span class="page-gap" aria-hidden="true">…</span>` (40 px slot, muted, not focusable, not clickable). The `<nav>` keeps its `aria-label` `"Pages, page <page> of <totalPages>"` (already built in story "See my brews in the journal"). ‹ and › keep their behavior. The phone layout ("PAGE <n> OF <total>") is unchanged and shows no gaps.

## Hard logic
```ts
if (totalPages <= 7) return 1..totalPages;
const keep = sorted unique of [1, page - 1, page, page + 1, totalPages] within 1..totalPages;
let prev = 0;
for (const p of keep) {
  if (p - prev === 2) out.push(prev + 1);   // a one-page gap shows the number
  else if (p - prev > 2) out.push('gap');
  out.push(p); prev = p;
}
```
