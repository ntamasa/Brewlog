**Goal:** Create the Angular 22 app in `frontend/` with its tooling, routes and CI workflow, so later subtasks only add screens.

**Read first:**
- Epic → Technical design → Overview, Conventions, Risks
- Story → Repository and tooling, Prerequisites, Frontend, CI

## Files that change
- create `.nvmrc` (repo root): the single line `24`.
- create `frontend/` with `npx @angular/cli@22 new frontend --style=scss --routing --ssr=false --zoneless --skip-git` (standalone components, Vitest runner). Then add `@angular/material`, `@angular/cdk`, `@angular/material-date-fns-adapter`, `date-fns`, `@ngrx/signals`; angular-eslint with `ng add angular-eslint`; Prettier as a dev dependency. Every generated file stays as generated, except the ones this list deletes or modifies.
- delete `frontend/README.md` and `frontend/src/app/app.spec.ts` (generated).
- modify `frontend/.prettierrc` (generated, with `printWidth` 100, `singleQuote` true and the `*.html` → `angular` parser override): add only `"endOfLine": "auto"` (Epic → Risks, line endings). Create no other Prettier config file: no `.prettierrc.json`, no `.prettierignore`, no `prettier` key in `package.json`.
- modify `frontend/package.json`: add `"engines": { "node": "^24.15.0" }`. Scripts: `start` = `ng serve --proxy-config proxy.conf.json`, `test` = `ng test --watch=false`, `lint` = `ng lint`, `format:check` = `prettier --check "src/**/*.{ts,html,scss,css,json}"`, `format` = `prettier --write "src/**/*.{ts,html,scss,css,json}"`, `build` = `ng build`.
- create `frontend/proxy.conf.json`: `/api` → `http://localhost:8080`, `secure: false`.
- modify `frontend/src/app/app.ts` / `app.html`: the root `App` renders only `<router-outlet />`. Remove the generated `title` signal and the placeholder markup; `app.html` holds the single line `<router-outlet />`.
- create `frontend/src/app/app.routes.spec.ts`: the router tests below.
- modify `frontend/src/app/app.routes.ts`: `''` → `LandingPage`, `'journal'` → `JournalPage`, `'**'` → `redirectTo: ''`.
- modify `frontend/src/app/app.config.ts`: `provideZonelessChangeDetection()`, `provideRouter(routes, withInMemoryScrolling({ anchorScrolling: 'enabled', scrollPositionRestoration: 'enabled' }))`, `provideHttpClient()`, `provideDateFnsAdapter(BREWLOG_DATE_FORMATS)`, `{ provide: MAT_DATE_LOCALE, useValue: enGB }` (from `date-fns/locale`).
- create `frontend/src/app/core/date-formats.ts`: `BREWLOG_DATE_FORMATS` (parse `dateInput: 'd MMM yyyy'`; display `dateInput: 'd MMM yyyy'`, `monthYearLabel: 'MMM yyyy'`, `dateA11yLabel: 'd MMMM yyyy'`, `monthYearA11yLabel: 'MMMM yyyy'`).
- create `frontend/src/app/landing/landing-page/landing-page.ts` (+ `.html`, `.scss`): empty placeholder, filled in by the landing subtask.
- create `frontend/src/app/journal/journal-page/journal-page.ts` (+ `.html`, `.scss`): empty placeholder, filled in by the next story.
- create `.github/workflows/frontend.yml` as in Story → CI: trigger `pull_request` with paths `frontend/**` and `.github/workflows/frontend.yml`; steps `actions/checkout`, `actions/setup-node` with `node-version-file: .nvmrc` and `cache: npm`, `cache-dependency-path: frontend/package-lock.json`; then in `frontend/` (`defaults.run.working-directory: frontend`) `npm ci`, `npm run lint`, `npm run format:check`, `npm test`, `npm run build`. No hard-coded Node version anywhere in the workflow.
- Last step, after the scaffold and all edits above: run `npm run format` once in `frontend/`, so every file passes `npm run format:check`.

**Layout convention for all later subtasks:** one folder per component, `<name>/<name>.ts`, `.html`, `.scss`, `.spec.ts`, class name without a `Component` suffix (`BrewCard`, not `BrewCardComponent`). Services, stores and helpers are flat files where the spec names them (`core/brew-api.ts`, `journal/journal.store.ts`, `brew-form/brew-form.ts`).

## Names and signatures
- `export const routes: Routes` in `app.routes.ts`, `export const appConfig: ApplicationConfig` in `app.config.ts`
- `export class LandingPage`, `export class JournalPage`

## Tests that prove it
**Seam:** router · **Setup:** `frontend/src/app/app.routes.spec.ts`, TestBed with `provideRouter(routes)` and `RouterTestingHarness` · **Mocked:** nothing

**Happy path**
1. Given the routes, when navigating to `''`, then `LandingPage` is rendered.
2. Given the routes, when navigating to `/journal`, then `JournalPage` is rendered.

**Negative**
3. Given the routes, when navigating to `/does-not-exist`, then the router ends on `/` and renders `LandingPage`.

- `frontend/.prettierrc` is the generated file plus `"endOfLine": "auto"` and is the only Prettier config; `frontend/README.md` and `frontend/src/app/app.spec.ts` don't exist; `App` has no `title`.
