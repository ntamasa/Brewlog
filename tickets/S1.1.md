**Goal:** Create the Angular 22 app in `frontend/` with its tooling, routes and CI workflow, so later subtasks only add screens.

**Read first:**
- Epic → Technical design → Overview, Conventions, Risks
- Story → Repository and tooling, Frontend, CI

## Files that change
- create `frontend/` with `npx @angular/cli@22 new frontend --style=scss --routing --ssr=false --zoneless --skip-git` (standalone components, Vitest runner). Then add `@angular/material`, `@angular/cdk`, `@angular/material-date-fns-adapter`, `date-fns`, `@ngrx/signals`; angular-eslint with `ng add angular-eslint`; Prettier as a dev dependency.
- create `frontend/.prettierrc.json`: `{ "singleQuote": true, "printWidth": 100 }`, and `frontend/.prettierignore` (`dist`, `.angular`, `public/icons.svg`).
- modify `frontend/package.json` scripts: `start` = `ng serve --proxy-config proxy.conf.json`, `test` = `ng test --watch=false`, `lint` = `ng lint`, `format:check` = `prettier --check "src/**/*.{ts,html,scss,css,json}"`, `format` = `prettier --write "src/**/*.{ts,html,scss,css,json}"`, `build` = `ng build`.
- create `frontend/proxy.conf.json`: `/api` → `http://localhost:8080`, `secure: false`.
- modify `frontend/src/app/app.ts` / `app.html`: the root `App` renders only `<router-outlet />`.
- modify `frontend/src/app/app.routes.ts`: `''` → `LandingPage`, `'journal'` → `JournalPage`, `'**'` → `redirectTo: ''`.
- modify `frontend/src/app/app.config.ts`: `provideZonelessChangeDetection()`, `provideRouter(routes, withInMemoryScrolling({ anchorScrolling: 'enabled', scrollPositionRestoration: 'enabled' }))`, `provideHttpClient()`, `provideDateFnsAdapter(BREWLOG_DATE_FORMATS)`, `{ provide: MAT_DATE_LOCALE, useValue: enGB }` (from `date-fns/locale`).
- create `frontend/src/app/core/date-formats.ts`: `BREWLOG_DATE_FORMATS` (parse `dateInput: 'd MMM yyyy'`; display `dateInput: 'd MMM yyyy'`, `monthYearLabel: 'MMM yyyy'`, `dateA11yLabel: 'd MMMM yyyy'`, `monthYearA11yLabel: 'MMMM yyyy'`).
- create `frontend/src/app/landing/landing-page/landing-page.ts` (+ `.html`, `.scss`): empty placeholder, filled in by the landing subtask.
- create `frontend/src/app/journal/journal-page/journal-page.ts` (+ `.html`, `.scss`): empty placeholder, filled in by the next story.
- create `.github/workflows/frontend.yml` as in Story → CI.

**Layout convention for all later subtasks:** one folder per component, `<name>/<name>.ts`, `.html`, `.scss`, `.spec.ts`, class name without a `Component` suffix (`BrewCard`, not `BrewCardComponent`). Services, stores and helpers are flat files where the spec names them (`core/brew-api.ts`, `journal/journal.store.ts`, `brew-form/brew-form.ts`).

## Names and signatures
- `export const routes: Routes` in `app.routes.ts`, `export const appConfig: ApplicationConfig` in `app.config.ts`
- `export class LandingPage`, `export class JournalPage`

## Tests that prove it
**Seam:** router · **Setup:** TestBed with `provideRouter(routes)` and `RouterTestingHarness` · **Mocked:** nothing

**Happy path**
1. Given the routes, when navigating to `''`, then `LandingPage` is rendered.
2. Given the routes, when navigating to `/journal`, then `JournalPage` is rendered.

**Negative**
3. Given the routes, when navigating to `/does-not-exist`, then the router ends on `/` and renders `LandingPage`.

## Out of scope
- Theme, fonts and icons (S1.2). Landing content (S1.3). Backend (S1.4). Docker and e2e (S1.5).

## Done when
- `cd frontend && npm run lint && npm run format:check && npm test && npm run build` passes.
