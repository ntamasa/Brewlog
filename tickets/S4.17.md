## Names and signatures
- The 4 keys, so a disabled segment looks like an enabled one:
  - `disabled-state-text-color: var(--color-on-surface)`
  - `disabled-state-background-color: transparent`
  - `disabled-selected-state-text-color: var(--color-on-primary)`
  - `disabled-selected-state-background-color: var(--color-primary)`
- Scoped to `.segmented`, so the "Filter & sort" sheet's roast control (BREW-52) gets the same look.
- Locators: `light`, `medium`, `dark` = `drawer.locator("mat-button-toggle", { hasText: "Light" })` (and "Medium", "Dark"): the host element, which carries the colours and the classes `mat-button-toggle-checked` and `mat-button-toggle-disabled`. Each one's button is `.locator("button")`.

## Tests that prove it
**Seam:** E2E · **Setup:** the existing held-POST test of BREW-105 in `e2e/tests/brew-form.spec.ts` (Pour Over, Light, 5 beans; the POST held 2.5 s), both projects · **Mocked:** nothing

Colours as computed: espresso `rgb(43, 29, 22)`, ivory `rgb(250, 246, 238)`, transparent `rgba(0, 0, 0, 0)`. Every check is Playwright's retrying `await expect(locator).toHaveCSS(name, value)` (the toggle animates its background), never a one-shot `getComputedStyle` or `evaluate`. Colours are read on the host, never on its inner `button.mat-button-toggle-button`, whose background stays transparent.

Red step: before the theme change, test 1 fails (Light's background is Material's on-surface at 12%, its text on-surface at 38%).

**Happy path**
1. In the held "Saving…" state, `light` has `background-color` `rgb(43, 29, 22)` and `color` `rgb(250, 246, 238)` (R12: selected = espresso fill, ivory text).
2. In that state, `medium` and `dark` each have `color` `rgb(43, 29, 22)` and `background-color` `rgba(0, 0, 0, 0)`: their normal look on the group's surface.

**Negative**
3. In that state, `light`, `medium` and `dark` each have the class `mat-button-toggle-disabled`, each one's button is disabled (`toBeDisabled()`), and only `light` has the class `mat-button-toggle-checked`: the look changed, the segments are still disabled (R49).
