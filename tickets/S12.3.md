## Names and signatures
- `BeanRating` (input mode): `beanLabels = input<string[] | null>(null)`: when set, bean i's radio gets `aria-label` `beanLabels[i-1]`; `showText = input(true)`: false hides the "n of 5" / "Not rated" text. The defaults keep the brew form as it is.
- `FiltersSheet` (injects `JournalStore` and `MethodStore`; every change calls `store.setFilter(...)` / `store.setSort(...)` at once, so the list and count update live): title "Filter & sort", Method `mat-select` (All methods + `methodsAz`), Roast segmented `mat-button-toggle-group` (All / Light / Medium / Dark), "Minimum rating" `BeanRating` in input mode (44 px targets, `aria-label` "Minimum rating", `showText` false, `beanLabels` `["Any rating", "At least 2 beans", "At least 3 beans", "At least 4 beans", "At least 5 beans"]`, value `query().minRating ?? 1`) with the legend `minRatingLegend(query().minRating)`, Sort `mat-select`; footer ghost "Clear all" (`store.clearFilters()`) + primary `"Show " + brewCount(matchingCount)` (closes the sheet).
- Bean picker change to `v`: `store.setFilter({ minRating: v === 1 ? null : v })`. `minRating` 1 is never sent. Tapping the already selected bean changes nothing.
- `minRatingLegend(minRating: number | null): string`, exported from `filters-sheet.ts`: null → "Any rating", 2–4 → "<n>+ beans", 5 → "5 beans only".

## Tests that prove it
**Seam:** component (`FiltersSheet`) · **Setup:** TestBed, fake `JournalStore` state, harnesses · **Mocked:** stores

**Happy path**
1. Given `matchingCount` 3, then the primary reads "Show 3 brews"; given 1, "Show 1 brew" (R6, B23).
2. When Roast "Light" is tapped, then `setFilter({ roast: 'LIGHT' })` is called (R6).
3. Given `minRating` null, then exactly 1 bean is filled and the legend reads "Any rating" (R44).
4. Given `minRating` null, when bean 4 is tapped, then `setFilter({ minRating: 4 })` is called; given `minRating` 4, 4 beans are filled and the legend reads "4+ beans" (R44).
5. When bean 5 is tapped, then `setFilter({ minRating: 5 })` is called; given `minRating` 5, the legend reads "5 beans only" (R44).
6. Given `minRating` 4, when bean 1 is tapped, then `setFilter({ minRating: null })` is called; given `minRating` null afterwards, 1 bean is filled and the legend reads "Any rating" (R44).
7. The 5 bean radios have the accessible names "Any rating", "At least 2 beans", "At least 3 beans", "At least 4 beans", "At least 5 beans" (R44).
8. When "Clear all" is tapped, then `clearFilters()` is called (R6).

**Negative**
9. Given `minRating` null, when bean 1 is tapped, then `setFilter` is never called with `minRating: 1` (R44).
10. `minRatingLegend`: null → "Any rating", 2 → "2+ beans", 3 → "3+ beans", 4 → "4+ beans", 5 → "5 beans only" (R44).
