## Names and signatures
- The roast group becomes `<mat-button-toggle-group class="segmented" formControlName="roast" aria-label="Roast level" hideSingleSelectionIndicator>`. Its three toggles and their swatches stay as they are.
- `.segmented` is the prototype's `.segmented` for a `mat-button-toggle-group`, and the roast of the "Filter & sort" sheet (BREW-52) uses it too. The `.mat-button-toggle-group` prefix outranks Material's own rules, whose styles load after the global stylesheet:
  ```scss
  .mat-button-toggle-group.segmented {
    display: grid;
    grid-auto-flow: column;
    grid-auto-columns: 1fr;
    width: 100%;
    padding: var(--spacing-xxs);
    gap: var(--spacing-xxs);
    background-color: var(--color-surface);
    @include mat.button-toggle-overrides((height: 38px, background-color: transparent));
  }
  .mat-button-toggle-group.segmented .mat-button-toggle {
    border-radius: var(--radius-sm);
  }
  .mat-button-toggle-group.segmented .mat-button-toggle + .mat-button-toggle {
  ```

## Tests that prove it
**Seam:** component (`BrewForm`) · **Setup:** as `brew-form.spec.ts` (BREW-22, with the provider of BREW-100 and the field ids of BREW-101), `MatButtonToggleHarness` · **Mocked:** HTTP

**Happy path**
1. Given the create form, when "Light" is checked, then:
   - `form.controls.roast.value` is "LIGHT"
   - Light is the only checked toggle
   - the group contains no `mat-pseudo-checkbox` and no `.mat-button-toggle-checkbox-wrapper` element (R12)
2. Given the create form, then the roast group has the class `segmented`, the role `radiogroup` and the aria-label "Roast level". Its toggles read "Light", "Medium" and "Dark", and each holds its swatch (`.swatch-light`, `.swatch-medium`, `.swatch-dark`) (R17).

**Negative**
3. Given the create form, then no toggle is checked and the group contains no `mat-pseudo-checkbox` (B2).
4. Given Light checked, when "Dark" is checked, then the value is "DARK", Light isn't checked any more, and the group still contains no `mat-pseudo-checkbox`.

**Seam:** E2E · **Setup:** like the create test in `e2e/tests/brew-form.spec.ts` (BREW-99), both projects · **Mocked:** nothing

Both cases are one new test. The group is `group = drawer.getByRole("radiogroup", { name: "Roast level" })`, and the Light toggle is its host element `light = drawer.locator("mat-button-toggle", { hasText: "Light" })`, the element that gets the class `mat-button-toggle-checked`.

5. Given the form open, then, measured with `boundingBox()` of the group and its three `mat-button-toggle` hosts:
   - first the drawer has settled: `await expect(drawer).toHaveClass(/mat-drawer-opened/)`, then `await expect(drawer).not.toHaveClass(/mat-drawer-animating/)`. The drawer's 400 ms slide moves every box, and each `boundingBox()` call reads a different frame
   - the three roast toggles' widths are equal within 0.5 px (equal-width segments filling the row: `design/screens/brew-form.md` → Roast level, `brew-form.create.desktop.png`)
   - the gap from the group's left edge to the first toggle's left edge, and from the last toggle's right edge to the group's right edge, is each 3 px (1 px border + 2 px padding) within 0.5 px: 2.5 ≤ gap ≤ 3.5. The `1fr` columns are laid out in sub-pixel units, so a gap isn't exactly 3 at every width (at 1440 px the right one is 3.015625)
   - the group is 44 px tall
6. Given test 5's settled form, when "Light" is clicked, then the `light` host settles at the selected colours and the group has no checkmark, each checked with Playwright's auto-retrying assertions on the settled state:
   - `await expect(light).toHaveCSS("background-color", "rgb(43, 29, 22)")`
   - `await expect(light).toHaveCSS("color", "rgb(250, 246, 238)")`
   - `await expect(group.locator(".mat-pseudo-checkbox")).toHaveCount(0)`
   - never a one-shot `getComputedStyle` or `evaluate` read right after the click: the toggle animates its background, which reads "rgba(0, 0, 0, 0)" right after the click and reaches "rgb(43, 29, 22)" after about 76 ms
   - both colours on the host, never on its inner `button.mat-button-toggle-button`, whose background stays "rgba(0, 0, 0, 0)" (`background: none`) and whose colour only inherits the host's
