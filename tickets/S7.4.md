## Names and signatures
- `ObjectNode` is `tools.jackson.databind.node.ObjectNode` everywhere.
- `InvalidBodyException(String field)`: `RuntimeException`, getter `String field()`.
- `void BrewDraft.apply(ObjectNode body)`, as in Story → Hard logic → `draft.apply`, with these Jackson 3 calls only (never the coercing `asString()`, `asInt()`, `asLong()`):

```text
null:                       v.isNull()
text keys, brewDate:        v.isString(), then v.stringValue()
methodId:                   v.isIntegralNumber() && v.canConvertToLong(), then v.longValue()   // canConvertToLong() alone accepts 3.0
rating:                     v.isIntegralNumber(), then v.canConvertToInt() ? v.intValue()
                              : (v.bigIntegerValue().signum() > 0 ? Integer.MAX_VALUE : Integer.MIN_VALUE)
brewDate:                   LocalDate.parse(text); DateTimeParseException → InvalidBodyException("brewDate")
unknown keys (body order):  body.propertyNames()
```

- `BrewService.create(ObjectNode body): BrewResponse`: `BrewDraft draft = new BrewDraft(); draft.apply(body);`, then as today (validate with `selfId` null, `ValidationException`, `new Brew(…)`, `saveAndFlush`).
- `BrewController.create(@RequestBody ObjectNode body)`: the same 201 with `Location` as today. Jackson itself rejects a body that isn't an object, an empty body and malformed JSON, and Spring answers its plain 400: no code for that.
