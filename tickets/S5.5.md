**Goal:** Give each brew text limit one shared constant and the message value one helper in the brew form, with no change in behaviour.

**Source (review of PR #7):** the notes limit 2000 is written in the form's counter (`frontend/src/app/brew-form/brew-form.ts:123`, `:126`, `brew-form.html:162`) and again in `brew-validators.ts:31`; the 100s of name, bean name and origin and the numbers in the TOO_LONG messages are separate literals too. `field === 'name' ? …trim() : undefined` is written twice, in `fieldMessage` (`brew-form.ts:138`) and in `setServerFieldErrors` (`brew-form.ts:211`).

## Files that change
- create `frontend/src/app/core/brew-limits.ts`: the constant below, and nothing else. It lives in `core/` because `core/error-messages.ts` needs it too, and `core/` never imports from `brew-form/`.
- modify `frontend/src/app/brew-form/brew-validators.ts`: `BREW_VALIDATORS.name`, `.beanName`, `.origin` use `maxTrimmedLength(BREW_TEXT_LIMITS.<field>)`, `.notes` uses `maxTrimmedLength(BREW_TEXT_LIMITS.notes)`. No other change.
- modify `frontend/src/app/core/error-messages.ts`: the four TOO_LONG texts become template strings with `${BREW_TEXT_LIMITS.<field>}`, e.g. `` `Tasting notes can be at most ${BREW_TEXT_LIMITS.notes} characters` ``. The resulting texts don't change (no thousands separator: "2000").
- modify `frontend/src/app/brew-form/brew-form.ts`:
  - `counterText`: `` `${this.notesLength().toLocaleString('en-US')} / ${BREW_TEXT_LIMITS.notes.toLocaleString('en-US')}` `` (still "1,801 / 2,000").
  - `notesState`: `> BREW_TEXT_LIMITS.notes` instead of `> 2000`; the `> 1800` stays as it is. Make it `protected readonly` (it is `private` today) so the template can read it.
  - the new helper `messageValue` (below). `fieldMessage` passes `this.messageValue(field)` as the third argument. In `setServerFieldErrors`, remove `const name = …`, cast `field` to `keyof BrewFormControls` right after the `Object.hasOwn` check, and pass `this.messageValue(key)` to `brewFieldMessage`.
- modify `frontend/src/app/brew-form/brew-form.html`: `@if (notesLength() > 1800)` becomes `@if (notesState() !== 'none')`, and `[class.counter-error]="notesLength() > 2000"` becomes `[class.counter-error]="notesState() === 'over'"`.
- No `.spec.ts` file changes.
