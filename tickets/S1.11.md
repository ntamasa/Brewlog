**Goal:** Make `build-icons.mjs` read `icons.js` as data against an allow-list instead of evaluating it, and guard the committed sprite with an allow-list test.

**Source (review of PR #3):** Technical design → UI implementation, "Icon build script" bullet (quoted here because the whole UI implementation section no longer fits one Jira description):

> Icon build script (from grilling): `frontend/scripts/build-icons.mjs` reads `design/prototype/icons.js` as data and never evaluates it (no `eval`, `new Function` or `import` of it), with no new dependency:
> 1. Take the lines between the line containing `var symbols = {` and the next line that is only `};`.
> 2. Skip blank lines and lines starting with `//` (after leading spaces).
> 3. Every other line must match `^\s*(?:'([a-z0-9-]+)'|([a-z0-9-]+)):\s*'([^'\\]*)',?\s*$` (key, value); otherwise throw `icons.js line <n>: not a symbol entry`.
> 4. Each value must consist only of self-closing tags `<path|circle|ellipse|rect attr="…" />`, whose attributes are among `d`, `cx`, `cy`, `r`, `rx`, `ry`, `x`, `y`, `width`, `height`, `transform`, `style`, whose values contain none of `<`, `>`, `"`, `&`, and whose `style` is exactly `fill:currentColor` or `stroke:var(--color-surface)`; otherwise throw `icon <key>: <tag|attribute|style> <value> not allowed`.
> 5. Write `public/icons.svg` as before: `<svg xmlns="http://www.w3.org/2000/svg"><defs>` + per key `<symbol id="<key>" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.25" stroke-linecap="round" stroke-linejoin="round">…</symbol>` + `</defs></svg>` and a final newline.
>
> `frontend/src/app/core/icons-sprite.spec.ts` also guards the committed sprite: parsed with `DOMParser`, every element is `svg`, `defs`, `symbol`, `path`, `circle`, `ellipse` or `rect`, and every attribute is one of the step 4 list, `xmlns` on `svg`, or `id`, `viewBox`, `fill`, `stroke`, `stroke-width`, `stroke-linecap`, `stroke-linejoin` on `symbol`.

## Names and signatures
- Error messages of the script, exactly (from steps 3 and 4):
  - `icons.js line <n>: not a symbol entry`, `<n>` = the 1-based line number in `icons.js`
  - `icon <key>: tag <name> not allowed`: a tag other than `path`, `circle`, `ellipse`, `rect`
  - `icon <key>: attribute <name> not allowed`: an attribute outside the step 4 list
  - `icon <key>: attribute <name>="<value>" not allowed`: an attribute value containing `<`, `>` or `&`
  - `icon <key>: style <value> not allowed`: a `style` other than the two allowed ones
  - `icon <key>: tag <rest> not allowed`: text in a value that isn't a self-closing tag, `<rest>` = the value from there to its end, trimmed
- In `icons-sprite.spec.ts`: `function disallowedParts(svgText: string): string[]` parses `svgText` with `new DOMParser().parseFromString(svgText, 'image/svg+xml')` and visits the root element and then every descendant in document order. For an element whose `localName` isn't one of the 7 allowed it adds `element <localName>` and skips its attributes. For every other attribute that isn't allowed it adds `attribute <name> on <localName>`. An attribute is allowed if it's in the step 4 list, or it's `xmlns` on `svg`, or it's `id`, `viewBox`, `fill`, `stroke`, `stroke-width`, `stroke-linecap` or `stroke-linejoin` on `symbol`.

## Hard logic
```js
// value = the third capture group of the step 3 line regex
const TAG = /\s*<([A-Za-z][\w-]*)((?:\s+[\w:-]+="[^"]*")*)\s*\/>/y; // one self-closing tag at lastIndex
const ATTR = /\s+([\w:-]+)="([^"]*)"/g;
let pos = 0;
while (pos < value.length) {
  TAG.lastIndex = pos;
  const tag = TAG.exec(value);
  if (!tag) {
    const rest = value.slice(pos).trim();
    if (!rest) break;
    throw new Error(`icon ${key}: tag ${rest} not allowed`);
  }
  // tag[1]: name → tag check; each ATTR match in tag[2]: name check, then value
  // characters (attribute name="value"), then the style check, in that order
  pos = TAG.lastIndex;
}
```
