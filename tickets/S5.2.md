## Names and signatures
- `brew-validators.ts` (Angular `ValidatorFn`s whose error keys are the API codes):
  - `requiredTrimmed: ValidatorFn` → `{ REQUIRED: true }` when the value is null, or a string that is empty after `trim()`
  - `maxTrimmedLength(max: number): ValidatorFn` → `{ TOO_LONG: true }` when `value.trim().length > max`
  - `notAfterToday: ValidatorFn` → `{ FUTURE_DATE: true }` when the `Date` is after today (browser local date, compared with date-fns `isAfter(startOfDay(value), startOfDay(new Date()))`)
  - `BREW_VALIDATORS: Record<keyof BrewFormControls, ValidatorFn[]>`: name/beanName/origin `[requiredTrimmed, maxTrimmedLength(100)]`, methodId/roast/rating `[requiredTrimmed]`, brewDate `[requiredTrimmed, notAfterToday]`, notes `[maxTrimmedLength(2000)]`
- `error-messages.ts`: `brewFieldMessage(field: string, code: string, value?: string): string` with exactly the texts of R13, R15, R16, R18, R19 (e.g. `('origin','REQUIRED')` → "Enter where the beans are from", `('methodId','REQUIRED')` → "Choose a brew method", `('rating','REQUIRED')` → "Choose a rating from 1 to 5 beans", `('rating','OUT_OF_RANGE')` → "Choose a rating from 1 to 5 beans", `('roast','INVALID')` → "Choose a roast level", `('brewDate','REQUIRED')` → "Choose a date", `('brewDate','FUTURE_DATE')` → "The date can’t be in the future", `('name','DUPLICATE', 'kenyan morning')` → "You already have a brew called “kenyan morning”. Brew names must be unique, ignoring capitals.", `('methodId','METHOD_NOT_FOUND')` → "This method no longer exists. Choose another one."). Curly quotes and apostrophes exactly as in the spec.
- `api-error.ts`: `parseApiError(err: unknown): ApiError` with `interface ApiError { kind: 'fields' | 'notFound' | 'protected' | 'network'; fields: ApiFieldError[]; code: string | null }`: 400 with a non-empty `errors` array → `fields`; 404 → `notFound` with `code` from the body; 409 → `protected` with `code`; everything else (status 0, 5xx, a 400 without `errors`, non-HTTP errors) → `network`.

## Tests that prove it
**Seam:** unit · **Setup:** Vitest, `FormControl`s, `vi.setSystemTime(new Date(2026, 10, 1, 9, 0))` · **Mocked:** nothing

**Happy path**
1. `requiredTrimmed` on "Kenyan Morning" → null; `maxTrimmedLength(100)` on 100 characters → null, and on `"  " + 100 characters + "  "` → null (R15, B3).
2. `notAfterToday` on 1 Nov 2026 → null (R18).
3. `brewFieldMessage` returns each text listed above for its field and code (R13, R15, R18).
4. `parseApiError` of a 400 `{errors:[{field:'name',code:'DUPLICATE'}]}` → `{kind:'fields', fields:[{field:'name',code:'DUPLICATE'}], code:null}`; of 404 `{code:'BREW_NOT_FOUND'}` → `{kind:'notFound', code:'BREW_NOT_FOUND', fields:[]}`; of 409 `{code:'PROTECTED'}` → `kind` `protected`.

**Negative**
5. `requiredTrimmed` on `"   "`, `''` and `null` → `{ REQUIRED: true }` (R13, R14).
6. `maxTrimmedLength(100)` on 101 characters → `{ TOO_LONG: true }`; `maxTrimmedLength(2000)` on 2001 → `{ TOO_LONG: true }` (R15).
7. `notAfterToday` on 2 Nov 2026 → `{ FUTURE_DATE: true }` (R18).
8. `parseApiError` of status 0, of 503, and of a 400 with no `errors` → `kind` `network` (R20, R41).
