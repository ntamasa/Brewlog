## Names and signatures
- `formOpen = signal(false)`; `sidenav = viewChild.required(MatSidenav)`. `BrewForm` is rendered in the sidenav only while `formOpen()` is true, and `(closed)` on the `mat-sidenav` sets it false (Hard logic).
- `JournalPage.openCreate()`: loads methods if `MethodStore.status()` is `idle`, sets `formOpen` true, then opens the sidenav in create mode. On `saved(brew)`: close, `Toaster.show('“' + brew.name + '” saved to your journal')`, `store.highlight(brew.id)`, `store.reload()`. On the form's `closed`: `sidenav().close()`, nothing else.
- Focus (R47): the sidenav moves it to the form's `[cdkFocusInitial]` Brew name once it has opened, and returns it to the element focused before it opened ("+ Add brew", the FAB or "+ Log your first brew") when it closes. `JournalPage` calls no `focus()` and nothing uses `cdkTrapFocus`.
- `BrewCard`'s `highlighted` = `brew.id === store.highlightId()`.

## Hard logic
```ts
openCreate(): void {
  if (this.methodStore.status() === 'idle') this.methodStore.load();
  this.formOpen.set(true);     // renders <app-brew-form> with its [cdkFocusInitial] input…
  void this.sidenav().open();  // …before the sidenav reports opened and focuses that selector
}
onFormClosed(): void {
  void this.sidenav().close(); // focus is still inside the sidenav, so it returns focus to the trigger
}
```
```html
<mat-sidenav mode="over" position="end" autoFocus="[cdkFocusInitial]" (closed)="formOpen.set(false)">
  @if (formOpen()) {
    <app-brew-form mode="create" [methods]="methods()" (saved)="onSaved($event)" (closed)="onFormClosed()" />
  }
</mat-sidenav>
```
Never remove the form before `close()`: with focus gone from the sidenav it returns none.
