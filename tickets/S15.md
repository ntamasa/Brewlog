As the coffee drinker, I want to add a new method right from the brew form, so that I can log a brew with a method that isn't in the list yet without leaving the form.

**Demo:** in the form's method list, "+ Add new method…", type "Chemex", "Add": while it saves, the input is disabled, "Add" is busy and "Add to journal" is blocked, both at 75% in their own colours; then Chemex is saved and selected, the other values stay. "pour over" gives "“Pour Over” already exists.". With the backend stopped, "Couldn’t save the method. Try again." and the input is enabled again with "Chemex" and focused.
